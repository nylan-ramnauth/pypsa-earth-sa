Module 04 — PyPSA-RSA + South Africa Source Audit Overview¶

This notebook reads every audit artefact produced by scripts/build_za_source_audits.py and renders a presentation-ready summary.

It is read-only with respect to the model. No fleet, carrier, cost, demand, or grid override is written here.

The PyPSA-RSA reference repo is pinned at commit 89872c1ea703af3d8a3f198706d1ab7958f50a5f. The pin matched both local HEAD and origin/main at module entry.
